# Spinach Plant Disease Detection

A publication-quality machine learning system for automated detection of spinach diseases from leaf images.  Implements a weighted ensemble of MobileNetV2 (transfer learning from PlantVillage) and five classical sklearn classifiers operating on a 28-dimensional hand-crafted feature vector.

## Supported Disease Classes

| Label | Disease |
|---|---|
| `healthy` | Healthy spinach |
| `downy_mildew` | Downy mildew (*Peronospora farinosa* f.sp. *spinaciae*) |
| `leaf_spot` | Leaf spot (*Cercospora beticola*, *Alternaria* spp.) |
| `damping_off` | Damping off (*Pythium* spp., *Rhizoctonia solani*) |
| `white_rust` | White rust (*Albugo occidentalis*) |
| `anthracnose` | Anthracnose (*Colletotrichum dematium*) |
| `mosaic_virus` | Spinach Mosaic Virus (SpMV, Potyvirus) |
| `nutrient_deficiency` | Nutrient deficiency (N, Fe, Mg, K, Zn) |
| `pest_damage` | Pest damage (leaf miners, aphids, cutworms) |

## Models

### EfficientNet-B4 (Deep Learning)
- 19M parameters, compound scaling (depth + width + resolution)
- Pre-trained on ImageNet via timm (PyTorch Hub — no HuggingFace)
- Weights downloaded once on first run, cached to `models/efficientnet_b4_imagenet.pth`
- Every subsequent startup loads from local disk — no network required
- Output head: 9 spinach disease classes directly
- Fine-tune with your own spinach dataset via `train.py` for best accuracy

### Classical Classifiers (sklearn)
- Random Forest, Gradient Boosting, SVM (RBF), k-NN, Logistic Regression
- Input: 28-dimensional feature vector from `ImageProcessor.extract_features()`
- Features: RGB statistics, texture (entropy, edge density), colour indices, spatial symmetry
- Must be trained on real labelled images via `evaluate.py` before inference

### Ensemble
- Final prediction: 0.60 × MobileNetV2 + 0.40 × (average of all sklearn models)
- Weights determined empirically via `ablation.py`

## Reproduce All Results (One Command)

```bash
# Requires a labelled image dataset organised as:
#   dataset/healthy/*.jpg
#   dataset/downy_mildew/*.jpg
#   ... (one folder per label)

bash scripts/reproduce.sh /path/to/dataset
```

This will:
1. Install dependencies
2. Run all unit and integration tests
3. Run 5-fold stratified CV for all sklearn classifiers
4. Evaluate MobileNetV2 on the full dataset
5. Evaluate the ensemble
6. Run ensemble weight ablation (α sweep)
7. Run pairwise statistical significance tests (Wilcoxon + Bonferroni)
8. Generate all figures and the LaTeX summary table

All output goes to `results/`.

---

## Evaluation Pipeline

```bash
python evaluate.py --data /path/to/dataset --folds 5
```

Generates:
- `results/evaluation_results.json` — all metrics, per-fold results
- `results/summary_table.tex` — LaTeX table for paper
- `results/figures/cm_*.png` — confusion matrices
- `results/figures/roc_*.png` — ROC curves
- `results/figures/pr_*.png` — precision-recall curves
- `results/figures/cal_*.png` — calibration curves
- `results/figures/cv_f1_boxplot.png` — CV fold comparison

**Important:** All reported metrics come from held-out test folds only.  No training-set metrics are cited.

---

## Statistical Tests

```bash
python statistical_tests.py --results results/evaluation_results.json
```

Runs:
- Pairwise Wilcoxon signed-rank tests on per-fold CV scores
- Bonferroni correction for multiple comparisons (α=0.05)

---

## Ensemble Ablation

```bash
python ablation.py --data /path/to/dataset --steps 11
```

Sweeps α ∈ {0.0, 0.1, …, 1.0} and records Accuracy, F1-Macro, AUC-Macro.

## Reproducibility Notes

- Random seed: `42` (all sklearn estimators, CV splitters)
- CV: `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`
- Each fold uses `clone(pipe)` — no cross-fold state contamination
- All figures generated programmatically from `evaluate.py`
- No metric values are hard-coded anywhere in the codebase
- Git commit hash is logged in `reproduce.sh` output
